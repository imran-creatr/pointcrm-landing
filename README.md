# PointCRM — лендинг

Лендинг CRM для автомоек: hero с 3D-телефоном (Three.js) и живым экраном сканирования номера, закреплённый блок «5 шагов» в стиле tinker.com, возможности, роли, сравнение, FAQ и CTA.

Статический сайт без сборки: `index.html`, `styles.css`, `main.js` (GSAP + ScrollTrigger + Lenis), `phone3d.js` (Three.js), `textures.js` (картинки для 3D-экранов).

## Запуск

Откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
npx serve .
```
